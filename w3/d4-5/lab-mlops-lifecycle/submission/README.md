# MLOps Lifecycle - Trần Đình Thông

Em chạy pipeline bằng Python 3.11. Từ thư mục này: cài dependency theo README của data pack, chạy `python pipeline.py --data ../data-pack/data/baseline.csv`, khởi động `python serve.py`, kiểm drift bằng `python drift_detector.py --reference ../data-pack/data/baseline.csv --current ../data-pack/data/drifted.csv --check-mode combined --labeled-current ../data-pack/data/drifted.csv`, rồi chạy `python retrain.py --reference ../data-pack/data/baseline.csv --current ../data-pack/data/drifted.csv --holdout ../data-pack/data/holdout.csv --post-deploy-eval ../data-pack/data/post_deploy_eval.csv`. Nếu `MLFLOW_TRACKING_URI` không được khai báo, code dùng MLflow file store tại `./mlruns`; khi stack Docker hoạt động có thể export URI `http://localhost:5000`.
